# 🧦 Doidas & Meias

E-commerce da Doidas & Meias, uma loja especializada em meias divertidas, criativas e diferentes.

## 🚀 Sobre o projeto

A Doidas & Meias é uma loja online desenvolvida para oferecer uma experiência simples, rápida e segura para compra de meias e kits.

O projeto conta com:

- 🛍️ Catálogo de produtos
- 🧦 Meias divertidas e 3D
- 🛒 Carrinho de compras
- 💳 Pagamento online
- 📦 Cálculo de frete
- 🔎 SEO para mecanismos de busca
- 📱 Layout responsivo para celular e computador
- 🔐 Área de cadastro e login de clientes
